# 設計討論與決策（先討論、後生成）

這是從與使用者的實際對話整理的決策摘要；不是虛構的會議紀錄。

1. **延伸主題：** 使用者選擇沿用第九週「My Paper Reading List」的學術閱讀主題，不另做不相干的知識庫。
2. **保留形式：** 使用者要求保留 HW9 的網站架構與視覺風格，輸出可以直接上傳 GitHub 的 HW10 ZIP。
3. **知識來源：** 使用者詢問是否能 ingest 自己找到的論文，之後提供 `papers.zip`。對資料做數量及可用性檢查後，採用其中 10 篇 PDF（高於至少 5 篇的作業要求）。
4. **教學設計：** 以「如何讀懂心理學研究」為主軸，把 HRV、壓力反應與 DRES 研究當成不同測量與研究設計的案例，而非宣稱所有文獻在研究同一個變項。
5. **公開界線：** GitHub Pages 只發佈自製 Wiki 學習摘要、DOI、圖表與程式碼，避免公開再散布使用者提供的論文 PDF 全文。
6. **知識與呈現的界線：** 由驗證後的 `wiki-sources.json`／`wiki-concepts.json` 支撐 `slide-plan.json`，再透過 `tools/build_slides.py` 產生 HTML。流程有檢查關卡與失敗返回路徑，但不是瀏覽器上的即時 LLM API。

## 原先作法與修改

最初易產生「收集 → 生成簡報 → 最後一次檢查」的直線型流程。本次改成三個關卡：來源 Gate、知識與引用 Gate、簡報 Gate。後續發現手機版版面溢出與測驗答案提前暴露時，再將兩項檢查提前到 CSS 基礎樣式／教學大綱節點。細節見 `test-report.md`。
