## 本機重新核對

原始 PDF 另存於本機的私有資料夾（本 ZIP 不附），指令：

```bash
python -m pip install pymupdf
python tools/ingest_local.py /path/to/papers --check
```

檢查：檔名、SHA256、頁數及擷取字元數與 `data/wiki-sources.json` 中的紀錄一致，才視為通過。這能驗證檔案是否為同一份，**不代表所有科學解讀已由程式自動驗證**。

## 注意

- `data/ingest-manifest.json` 是本次來源證據與步驟記錄，並非將 PDF 重新發佈。
- 所有實證主張至少可從 Wiki 的來源 ID、DOI 及標註的 PDF 頁碼開始追溯。若需核對統計量與表格，應重新檢視私有 PDF。
- 網站為靜態發佈成果；來源擷取由本機 Python 執行，Wiki 與教學整理是一次已完成的資料轉換，不是無人值守的雲端 LLM 服務。
